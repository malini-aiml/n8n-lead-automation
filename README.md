# AI Automation Developer Assignment: Lead Automation & AI Voice Integration

This repository contains the complete implementation for the AI Automation Developer assignment. The project focuses on building an automated backend data pipeline and AI voice agent tools using **n8n** and **LiveKit**.

---

## 🚀 Key Features Implemented

* **Real-Time Lead Management:** Automated data capture, processing, and seamless saving into Google Sheets.
* **Smart Email Automation:** Configured automatic conditional email routing and immediate lead responses.
* **LiveKit Voice AI Integration:** Structured specific tool-calling actions (`get-user-info`, etc.) allowing real-time data lookups during voice sessions.
* **Robust Workflow Design:** Modular error handling, precise data filtering, and optimized webhook management.

## 🛠️ How to Use & Import the Workflow

1. **Download the JSON:** Save the `My workflow 2.json` file from this repository to your local machine.
2. **Open n8n:** Go to your active **n8n** dashboard interface.
3. **Import File:** Click on the top-right menu icon (three dots) and choose **Import from File**.
4. **Deploy:** Upload the downloaded JSON file to instantly recreate the entire automation canvas with all nodes configured.
