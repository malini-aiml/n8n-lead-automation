# n8n Google Sheets + Gmail Automation
This project automates lead collection using n8n.

## Features
- Receives form data using Webhook
- Stores leads in Google Sheets
- Sends automatic Gmail reply
- Uses n8n workflow automation

## Technologies Used
- n8n
- Google Sheets API
- Gmail API
- Webhook Automation

## Workflow
Webhook → Google Sheets → Gmail
